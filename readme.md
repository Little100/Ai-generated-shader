# ai-generated-shader

## 这个仓库包含了我测试以来所有大模型对于我的世界光影制作的能力, 他们遵守:
  - 没有参考现有代码(指参考现有光影代码 比如bsl光影的)
  - 仅联网搜索api接口(联网搜索使用的grok)
  - 同一段提示词
    - 创建一个我的世界光影 完全按照你的想象去做 不允许抄袭现有的光影 仅允许使用websearch查找api,不允许直接标读取或者基于某款光影制作 , 目标版本 1.21.11, iris
  - 保证模型是真的模型不是掺水模型

## 格式为
 - 模型名字作为文件夹开头
 - 内部img为我上传图片用的
 - 内部readme.md为模型的使用情况外加模型原话(如果有)
 - 内部其他文件夹为光影总文件
