# Komorebi 木漏れ日

一个从零写起的 Minecraft 光影包，面向 **1.21.11 + Iris**。视觉目标只有一句话：**光是可以被揉碎的**。
核心不是把画面变亮，而是把树冠之下那种被筛过的、有呼吸感的光做出来。

## 概念

- **树叶光斑**：阴影不是硬边黑块，树冠该漏光的地方会漏光。程序化噪声在阴影上凿出孔洞，光斑会随时间缓慢移动。
- **三层天空色带**：天顶、中段、地平各自独立染色，日出日落时地平线能烧成暖色而不污染天顶。
- **云影爬过地面**：体积云的高度场投影到地表，云影缓慢漂移。下雨时天空整体压灰。
- **自己的星空**：球面分格哈希撒点，四层不同尺度，带闪烁与银河带。寒冷群系晴朗夜晚会出现极光。
- **水面**：三组正弦波叠加出波面，菲涅尔混合折射与反射，水底有网状焦散，深水自然吸成青色。
- **体积光柱**：真正穿过树冠间隙的光柱，逐点用阴影贴图判断是否在光里。
- **玻璃**：按透明度与不透明场景混合，染色玻璃会把颜色透到背后的东西上，并投出染色的阴影。
- **高度雾**：低处积雾、高处清澈，洞穴内另有一层静雾。下界与末地各有自己的雾色与光照。

## 安装

1. 安装 Iris（1.21.11 对应的版本）。
2. 把 `shaders` 文件夹整个放进 `.minecraft/shaderpacks/Komorebi/`，或把本目录打包成 zip 放进 `shaderpacks`。
3. 游戏内 `视频设置 → 光影` 选择 Komorebi。

## 选项

设置界面分五组：光照、大气、水体、后期、性能与兼容。另有 `LOW / MEDIUM / HIGH` 三个预设。

## 已知取舍

- 泛光金字塔在单个 pass 内以多重采样近似，改 `bloomStrength` 时柔和度会一起变化。
- 屏幕空间反射只在有几何体可采样的角度有效，水面平视远眺时完全依赖天空反射。
- 体积云与体积光都是纯屏幕空间的，不参与后续的时域累积，快速转视角时会看到轻微噪点。

## 自检工具

仓库根目录附带三个脚本，用于交付前验证（需要 Python 3 与 `glslangValidator`）：

```bash
python validate_glsl.py      # 展开 include 后逐个编译全部程序
python validate_variants.py  # 遍历每个选项的每个取值, 确认所有宏组合都能编译
python check_consistency.py  # 检查未被使用的选项、槽位编号与缓冲区读写
```

`glslangValidator` 路径通过环境变量 `GLSLANG` 指定，默认取 `%TEMP%\glslang\bin\glslang.exe`。
