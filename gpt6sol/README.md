# Loomlight (织光)

面向 Minecraft Java Edition 1.21.11 与 Iris 的原创光影包。画面以青蓝天空、杏金日光和靛色夜晚为主，保留原版方块纹理与形状，不使用其他光影包的代码或素材。

## 安装

将 `dist/Loomlight-1.0.0-Iris-1.21.11.zip` 放入 Minecraft 实例的 `shaderpacks` 文件夹，在 Iris 的光影包界面启用 `Loomlight`。压缩包内的根目录直接是 `shaders`。

## 画面与设置

- 动态天空含日月光盘、星点、程序化层云，并随昼夜和降雨改变色调。
- 自定义方块光照、柔和阴影、暖色方块光源、距离雾、水下与熔岩雾。
- 水面有轻微起伏、流动细纹与视角反光；树叶与草本植物随风摆动。
- 后处理包含低强度光晕、方块轮廓和细粒度抖动。
- 光影设置包含低、均衡、高三个预设，也可分别调节云量、阴影、雾、风与色彩。

选择较低预设可减少阴影采样与光晕开销。站在云层上方仍能看见下方的云面，其他维度会使用各自的简化天空与雾色。

## 开发

在项目根目录执行 `pwsh -File scripts/build.ps1` 可检查文件结构并重新生成压缩包。源码位于 `shaders`，通用实现位于 `shaders/lib`。`scripts/check.mjs` 是静态结构检查，不代替在 Minecraft 中观察实际画面和帧率。

本项目仅按 Iris 接口文档编写，未读取或基于其他现成光影包。目标版本为 1.21.11；真实游戏内的显卡、驱动和模组组合尚需本机验证。
