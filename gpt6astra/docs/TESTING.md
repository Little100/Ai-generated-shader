# Verification and in-game acceptance checklist

## 0.1.2 undefined format identifier regression

Reproduced the user's `RGBA16F` compile failure, plus the analogous shadow `RGBA8`
failure, using raw include-expanded sources without the old test-only macro
injection. All seven format declarations now use standalone lines within block
comments as required by the Iris format directive API. The test harness no longer
defines either format token. Twelve regression tests cover both metadata rules,
raw three-dimension prepare/deferred/composite/shadow stage links, and intentional
restoration of the broken declarations (which must fail with the original error).

The old driver/offline results were misleading for this case because the shared
harness supplied the missing macros. Results generated by 0.1.2 no longer do so.
Actual user-instance Iris loading still needs verification after replacement.

## 0.1.1 loading regression

The 0.1.0 build used scalar-splat `vec4(0.0)` in three Iris `ClearColor`
directives. Legal GLSL is not sufficient: Iris requires four explicit components
for this metadata. The new static validation checks all such directives, and
`python -m unittest discover -s tools -p "test_*.py"` rejects the original form.
A full user exception stack was not available; the exact runtime exception source
is therefore not claimed confirmed. Reload 0.1.1 in Iris to complete verification.

## Evidence categories

| Check | Result / limitation |
| --- | --- |
| Source includes, entry pairs, options, target sizes | Automated static checks |
| Shadow warp / tone-curve numerical properties | Finite and monotonic sample sweeps |
| LOW, BALANCED, HIGH, MINIMAL GLSL | 396 linked program pairs / 792 stages |
| Native driver, balanced all dimensions | 99 linked program pairs on AMD RX 7900 XT |
| Native GPU framebuffer pipeline | Eight authored synthetic scenarios; finite, nonempty RGB |
| Minecraft 1.21.11 + Iris runtime | **Not run** |
| NVIDIA / Intel / other OS / modpacks | **Not run** |
| In-game performance benchmarks | **Not measured** |

Offline compilation expands only this project's include tree and injects documented
Iris macro stand-ins. It does not simulate Iris' complete shader transformer.
LOW/BALANCED/HIGH enable the optional fade macro; MINIMAL tests the no-feature path.
Each preset is tested in world0, world-1 and world1. Root fallback includes are
statically checked and contain the same implementation as world0.

Native GPU preview geometry and texture are authored by this project. Even the
Nether/End previews deliberately reuse the synthetic estuary fixture to test
lighting changes; they are not representations of actual Minecraft dimensions.

Raw reports live at `build/validation/report.json` and `build/gpu/report.json`.
Both record a fingerprint of all shipped shader source/configuration. Packaging
refuses stale or failed full offline reports. A matching native-driver report is
included in the build manifest when present. The GPU checks do not invent FPS.

## Reproducible commands

```powershell
python tools/generate_programs.py
python tools/validate.py
python tools/gpu_smoke.py --render
python tools/package.py
```

`gpu_smoke.py --render` needs NumPy and Pillow. The default GPU compile-only mode
and static/GLSL checks use Python's standard library. No tool automatically fetches
anything from the internet. The native harness uses a never-shown WGL window and
cleans up its context, DC and window on completion.

## Required Minecraft acceptance pass (still unchecked)

### Loading / settings

- [ ] Launch the exact Minecraft **1.21.11** instance with matching Iris/dependencies.
- [ ] Select ZIP; inspect `latest.log` for the first shader compilation warning/error.
- [ ] Cycle LOW, BALANCED and HIGH, then change an individual option and apply.
- [ ] Verify Chinese/English labels, option ranges, and shadow distance changes.
- [ ] Resize window; switch fullscreen; verify half-resolution attachments rebuild.
- [ ] Toggle packs, reload resources, leave/rejoin world; check stale-buffer artifacts.

### Lighting / geometry

- [ ] Day/noon/dusk/night transition and light-direction handoff.
- [ ] Shadow acne/peter-panning on stairs, fences, farmland, thin models and leaves.
- [ ] Tall-grass lower/upper joining edge under wind, including its shadow.
- [ ] Turn shadow rendering off and inspect sealed caves for leaks.
- [ ] Move through newly generated chunks; no missing water from fade=-1.
- [ ] Test hurt entity tint, nametags, outlines and both first-person hands.
- [ ] Break a block and inspect its multiplicative cracks in dense fog.
- [ ] Inspect enchantment glint, glowing eyes and beacon halo against terrain AND sky.

### Transparent / media edge cases

- [ ] Stained glass casts tinted shadows and still displays its original texture.
- [ ] Glass/slime/honey behind water are not overwritten wholesale by the water layer.
- [ ] Multiple water layers, sloped flowing water, waterlogged blocks and bubble columns.
- [ ] Enter/exit water; check above/below-surface direction and total reflection region.
- [ ] Look through underwater glass at a distant wall: pane must not shorten wall absorption.
- [ ] Submerged lamps lose intensity/color before bloom extraction.
- [ ] Reflect water near screen edges and held items; no fictitious hand intersections.
- [ ] Firework/particle/weather ordering and translucent entities in front of water.
- [ ] Lava and powder-snow immersion; blindness, darkness pulses and night vision.

### Atmosphere / dimensions

- [ ] Rain starts/stops; wetness fades slowly and glass is not treated as terrain.
- [ ] Thin dark silhouettes do not inherit rejected bright half-resolution shaft samples.
- [ ] High-altitude builds and looking above/below the cloud slab.
- [ ] Enter Nether/End repeatedly; correct dimension programs and no stale shadows.
- [ ] Nether biome fog-color changes; End halo remains stable while looking around.
- [ ] Test a custom dimension: document generic fallback rather than claiming custom support.

## Bug-report essentials

Give the first Iris error, exact MC/Iris/Sodium versions, graphics driver/version,
OS, active profile/options, resourcepack and mod list, and a minimal screenshot or
location to reproduce. Reports should distinguish actual Minecraft output from
this repository's synthetic GPU previews. Do not supply another shaderpack as a
reference implementation: subsequent fixes should continue to be independently
authored against the relevant APIs.
