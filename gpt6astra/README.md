# 汀光 · Tidelume

**一套从空目录编写的原创 Minecraft Java 光影。**  
目标环境：**Minecraft Java 1.21.11 + 对应版本 Iris**。当前版本：**0.1.2 / 首个可测试版本**。

> 没有读取、下载、移植或修改任何现有光影包。GLSL 视觉实现、噪声组合、配色、材质分类、测试场景和工具均在本项目中编写。联网仅用于接口文档查询。使用通用数学与公开图形接口，不声称发明了阴影映射、菲涅耳或泛光这些通用原理。

## 0.1.2 格式声明编译修正

已复现用户报告的 `prepare.fsh: 'RGBA16F' : undeclared identifier`，并确认
阴影程序中的 `RGBA8` 也有同类缺陷。将七个格式声明放入 Iris 支持的块注释，
保持独立行的符号格式指令供加载器读取，同时不让它们进入 GLSL 编译器。

此前验证脚本额外注入了 `RGBA16F` / `RGBA8` 宏，因此没有发现这个真实编译错误；
现在已删除这些补定义。回归测试直接编译未注入任何宏的原始展开程序，并通过
故意恢复旧声明验证能够再次检出同一错误。没有更改视觉算法或降低 HDR 格式。

## 0.1.1 加载修正

针对用户报告的 `Index 1 out of bounds for length 1`，修正三处 Iris 清屏颜色声明：
将 `vec4(0.0)` 改成 `vec4(0.0, 0.0, 0.0, 0.0)`。Iris 的 ClearColor
配置要求显式列出四个分量；GLSL 本身允许的标量构造简写不能用于这里。
增加了加载元数据检查及针对旧写法的回归测试。视觉数值没有改变。

未拿到此次异常的完整堆栈，因此该配置缺陷已修正，但用户实例中的直接异常来源
仍待重新加载验证。该修正保留在 0.1.2 中；请在光影列表中明确选择 **0.1.2**。

## 视觉方向

「汀」是水边的平地。这套光影围绕河岸、林间与黄昏设计：

- **白天**：清透蓝青天幕，暖阳与偏冷的阴影分离，不铺满橙色滤镜。
- **黄昏**：沿太阳方向渐变的杏金／淡玫瑰色地平线。
- **夜晚**：靛蓝天空、细小星点、微亮月光；洞穴仍需要火把。
- **水面**：四组交叉的解析波纹、视角相关反射、岸边深浅变化与轻微折射。
- **下界**：保留生物群系雾色的温热浓雾。
- **末地**：深色天幕上悬着两道缓慢流动的冷绿／紫色光环。

## 安装

1. 在启动器中准备 **Minecraft Java 1.21.11**，安装与它匹配的 Iris 及其依赖。
2. 找到**当前游戏实例**的 `shaderpacks` 文件夹。使用版本隔离时，不一定是全局 `.minecraft/shaderpacks`。
3. 将 `dist/Tidelume-0.1.2-Iris-1.21.11.zip` 直接放进去，**不用解压**。
4. 在游戏的视频设置中进入 Iris 的光影选择界面，选择 Tidelume 并应用。
5. 光影设置提供中文／英文界面；首次建议选择 **均衡**，出现性能压力先切换 **轻量**。

也可将包含本项目 `shaders/` 的文件夹整体放入 `shaderpacks`。正确层级是 `shaderpacks/Tidelume/shaders/…`，而不是 `shaderpacks/shaders/…`。这不是资源包或模组，不放进 `resourcepacks` / `mods`。

## 明确的边界

- **不是路径追踪／硬件光追**；没有真实全局照明、体素 GI、PBR 贴图、视差遮挡、TAA 或动态分辨率。
- SSR 只能反射屏幕内的不透明内容，屏幕外回退到解析天空；反射里不绘制完整云层，也不包含透明物体。
- 水面使用适合排序透明混合的**标量透射近似**；折射只修正不透明快照的局部差值，不是多层折射追踪。透明物体相交、多个水面和水／空气边界的复杂叠层仍可能出现排序近似。
- 云层合成在天空背景上；没有实现山体穿云时完整的几何／云体积交互。
- 手持照明是无阴影局部近似，可能透过薄墙；发光方块增强不等于动态彩色光传播。
- 首版的水下信标外晕等不写深度的前置叠加效果仍按背景深度吸收，可能显得过弱；没有独立的逐层体积合成。
- 原版未列入分类和模组添加的方块会退回通用光照，不一定带专属风动或自发光。
- 首版没有 Distant Horizons 远景程序，也不声明 OptiFine、基岩版、Vulkan 转译层、第三方 PBR 资源包兼容。
- OpenGL shader 使用 `330 compatibility`；Iris 还需要提供 `ENTITY_TRANSLUCENT` 和 `PER_BUFFER_BLENDING` 特性。仅有“支持 GLSL 3.30”并不自动满足全部运行条件。

## 排错

- **不出现在光影列表中**：检查 ZIP 最上层是否直接包含 `shaders/`，以及是否放到了当前实例。
- **加载报错**：保留 Iris 的原始错误信息，记录第一个失败程序和行号；附上游戏、Iris、Sodium、显卡／驱动版本及当前实例的 `logs/latest.log` 中相关段落。错误行号可能对应展开后的 include。
- **太暗**：先确认没有失明／黑暗状态，再调“夜晚亮度”“方块光亮度”或“曝光”。不要为了照亮洞穴把全部画面冲白。
- **帧率下降**：先选轻量，再降阴影距离、云体采样；屏幕空间反射与体积光束是单独的开关。
- **水面边缘偶尔缺反射**：这是屏幕空间信息缺失的边界，不表示启用了完整世界的反射追踪。

## 开发与复现

```powershell
# 只生成薄入口文件，不生成视觉算法
python tools/generate_programs.py

# 不依赖 GPU 或第三方 Python 包
python tools/validate.py --static-only

# 要求 PATH 中有 Khronos glslangValidator
python tools/validate.py

# Windows 隐藏 WGL 上下文：真实驱动编译
python tools/gpu_smoke.py

# 额外要求 NumPy 与 Pillow；不读取游戏文件，不弹出窗口
python tools/gpu_smoke.py --render

# 要求当前源码的完整离线验证通过，生成 ZIP 与 SHA-256
python tools/package.py
```

项目不自动下载依赖、不扫描已有光影、不改动你的游戏目录、不启动游戏，也不部署到任何线上服务。

- `shaders/lib/`：原创共用实现。
- `shaders/program/`：各渲染阶段的主体。
- `shaders/world0/`、`world-1/`、`world1/`：对应原版三维度的薄入口。
- `shaders/` 根目录入口：其他维度的主世界风格回退。
- `docs/ARCHITECTURE.md`：缓冲区、合成顺序和取舍。
- `docs/API_REFERENCES.md`：允许范围内的接口文档来源。
- `dist/`：安装包与构建清单。
